Kya NA paste karein
-------------------
❌ service-account / admin key wali JSON (jis mein "type": "service_account" aur
   "-----BEGIN PRIVATE KEY-----" hota hai) — woh server ke liye hai, browser ke liye NAHI.
   Software aisi key ko pehchan kar mana kar deta hai.
❌ Rules wala text (rules_version / service cloud.firestore) — woh Rules tab mein jata hai.
❌ Sirf apiKey akela — poora JSON chahiye.

Ghalti ki nishani
-----------------
• Box khaali / adhoora → "Config khali hai" ya "Invalid config — apiKey ya projectId nahi mila"
• "client is offline" → internet/firewall ya databaseURL ghalat (upar wala URL sahi hai)
• "Permission denied" → Rules publish karne hain (FIREBASE-RULES-REALTIME.txt)
